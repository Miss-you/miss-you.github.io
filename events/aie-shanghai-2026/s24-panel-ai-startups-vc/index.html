据作者现场录音整理，按讲者脉络转述，不是逐字稿。其中开场、嘉宾自我介绍和第一个问题的回答部分据现场外部录音补全，未与本人录音对照。嘉宾是真格基金管理合伙人戴雨森、线性资本创始人兼 CEO 王怀南（Harry Wang）、TaoZ Capital 创始人 Patrick Liu，主持人是第二次用火创始人 Bibi。主持人问了四个问题：哪些赛道的应用被模型公司挤压、哪些有壁垒；怎么看 personal agent；2026 年拒得最多的方向；回到大学毕业、给你 200 万做什么。无观众问答。

一句话#

三位投资人都认为 AI 应用还没真正爆发，帮人省时间的 personal agent 天花板有限，情绪价值这类“能扩张的需求”更值得做。在人上，戴雨森基本不投只懂科研的教授团队，要动手做出结果的年轻人；Patrick 偏爱年轻老师加学生的组合；Harry 对上来就估值很高的 RSI 创业一个没投。

论断#

1. 吞掉小应用的是模型公司的第一方应用（戴雨森）#

第一个问题是：过去一年哪些赛道里模型公司已经明显挤压了应用，哪些赛道的应用有壁垒。戴雨森先答。他认为吞掉小应用公司的不是模型本身，而是模型公司自己做的第一方应用，而且这些应用补贴了 token。他整体看好：模型变强、变便宜，对应用公司是好事。

“其实我们看到所谓叫吞食小应用公司的，其实并不是模型本身，我认为，而是说模型公司它自己做的第一方的应用”

“但我整体觉得模型变强，然后变便宜，对应用公司是好事，而不是坏事”

  • 他说推理效率每年“可能提高 10 倍”，没给口径。
  • 从模型能力到商业化落地中间距离很大，要靠应用填补，应用可能是第一方做的，也可能是第三方做的。他类比操作系统刚出来时最好的几个应用也是平台自己做的，但上面照样长出了大量第三方应用生态。
  • 垂直应用的壁垒：他说在美国看到医疗、金融、法律领域的应用，相对大模型公司形成了 context、数据或部署上的壁垒。
  • 应用分两波：第一波面向喜欢折腾的用户，现在越来越多进入企业和普通人。
  • 下一阶段分两步：先让更多人用上更好的 AI 产品，再找 AI native 的商业模式。

2. 中国的模型公司没有边界，所以往软硬结合挪（Harry）#

Harry 认为纯软的大模型能力提升时，很容易吃掉纯应用企业的边界，这在美国也在发生，中国更甚。所以线性更多思考软硬结合。他说智能由三层组成：大模型本身的智能、帮你完成任务的 agentic、以及你的 context。

“那中国就不用说了，历史以来就从来没有边界这种说法”

  • 他同意智能越来越高、token 越来越便宜，但指出这说的是云端。他设想的是揣在兜里、能实时获取你的语音和日常行动等 context 的 personal agent，传感器和形态会和手机不同。
  • 他的 X 轴是软硬结合的 Local AI：对个人是新硬件，对企业是一个 enterprise box，企业能放心把 context 沉积在这个设备上，更高的需求再用云端。
  • Y 轴是不同的垂直领域，他说现在没有很好的答案；看到的一个方向是基于 diffusion 的实时视频生成，目标是把速度提高到原来的 20 倍以上，他说这是被迫绕开主模型的主战场。

3. 过去三年的应用公司大多出局，跑出来的是“最新模型套利”（Patrick）#

Patrick 对过去三年的总结：尤其在中国，三年前的应用层公司 90% 甚至 99% 已经出局（这几个字没听清，按上下文是这个意思），他说稍微统计过，限于拿过钱的公司；AI 应用还没完全开始爆发。他认为早期跑出来的公司是拿最新模型放到某个应用场景上，用户用通用模型不好使才付费，这是套利。

“这种套利的空间随着模型延伸到应用的时候就减少了”

  • “90% 甚至 99%”没给样本和口径。
  • 他自己加了限定：这个判断今天看来可能也不一定完全成立。

4. AI native 的方向已经出来了（Patrick）#

他说 AI native 的应用没有爆发，不等于方向没有出来。筛选标准是之前的技术解决不了、这一轮 AI 能做到。他看好三个方向：情绪价值；强数据相关、能慢慢积累形成数据效应的行业；以短剧为代表的内容生产。

“至少在今天哈， AI native 的，叫应用没有爆发，但不意味着 AI native 的方向没有出来……我自己特别看好的是就情绪价值的方向”

  • 强数据方向他说在美国很明显、在中国不明显，美国已经出现了很多法律类应用。
  • 他转述“有个上市公司说”，中文 AI 世界 token 消耗 55% 是短剧，而美国 token 主要花在生产工具上。没给公司名和口径，也没给美国的数字。
  • 情绪价值他在本场提了三次。他也说当下体验还不够，可能需要硬件辅助。

5. personal agent 不是刚需：提效、抢蛋糕、需求扩张（戴雨森）#

戴雨森认为 personal agent 对大部分人不是刚需，因为它主要在给已有任务提效。他说一些 personal agent 产品长期留存一般：短期帮你清了邮件订阅、找回没退的费用，之后你也不会天天订机票订酒店。移动互联网最大的公司都在让普通人的需求扩张。

“可能要真的做到一个大众市场，得是一个新需求扩张的一个产品，而不是一个已有需求提高效率的产品”

  • 正面设想：agent 了解你的生活习惯和身体状况，推荐你原来没想到买的补剂、给出个性化健身方案。
  • 把订机票从原来的平台切到 agent 上，是把中间人的钱分到自己兜里，他说这是抢别人蛋糕的市场，不是扩张型市场。
  • 他在第一个问题里说，personal agent 最后可能不靠订阅费挣钱，而是按帮用户省了多少钱、完成了多少交易额抽中间商费用。
  • 他说这是几十年来大家都想要的东西，每隔几年有人做一次，“这次我不知道是不是就 ready 了”。

6. personal agent 是大机会，但不是创业公司的机会（Patrick）#

Patrick 认为 personal agent 不管软件还是硬件都是大机会，但不属于创业公司：从算力、算法、数据三个维度看，做 personal agent 的创业公司都不会比大模型公司多。他还说过去好的商业模式里，帮人省时间的都不如帮人消耗时间的。

“如果说到 personal agents 的话，我觉得其实从，不管是软件和硬件，我认为它肯定是大机会，但是都不是创业公司”

  • 类比电脑和手机：操作系统层的技术最后被平台级公司占据。
  • 省时间的 personal agent 会越做越小，订机票这类需求不是无限的；情绪价值、娱乐、对信息的需求是无限的。
  • 他自己第一家公司做社交网络，第二家做游戏，说游戏行业里花钱越多的人越会花钱。

7. agent 要解决问题，非 coding 领域缺长程数据（Harry）#

Harry 说大模型做的是 next token prediction，聊天时是凑一段和你的问题比较和谐的 token，而 agent 的目的是解决问题。他理想的形态是一个大管家 agent 自动管理上下文、隔离 session，一个任务一个 context，用户只跟一个秘书 agent 打交道，不用自己开新 bot、新话题。

“今天大模型做得好的，其实就一个领域，就是 coding”

  • 他说 finance、travel 这类垂直领域里，用于长程任务的轨迹数据和环境远远不够。
  • 他转述一位硅谷大模型公司董事的说法：模型在生活问题上表现差、写代码却很聪明，是训练时优化方向的问题，“其实是他们 priority 的问题，并不是他能力做不到”。这是二手说法。

8. 基本不投教授型创业，要动手做出结果的人（戴雨森）#

被问到 2026 年拒得最多的方向，戴雨森说不按赛道看，按团队看。今年有很多年轻教授型创业，技术和科研很厉害，但对怎么做一家公司可能没想过，这类他们基本都没投。

“动手去做在这个时候就是非常重要的特质”

  • 他说搞科研和搞公司是两件很不一样的事，并且至少在中国，很难有像美国那样科研项目就能卖很多钱的退出方式。
  • 他看的是懂技术、至少有热情把产品和商业搞清楚，以及有没有已经做出来的结果和用户反馈。
  • 他区分天才和早慧：抛开年龄仍然很厉害才叫天才，成绩需要以年龄定义的叫早慧。
  • 真格在 2018 到 2019 年提出过“小天才、老司机、操盘手、科学家”的框架。

9. 年轻老师加学生的组合（Patrick）#

Patrick 当场说自己在这点上和戴雨森不一样，他挺喜欢年轻老师、年轻教授。理由是这一代 AI 的主要驱动力是技术，和移动互联网创业最大的差别是对技术的掌握和对趋势的把握。

“当然有一点跟雨森不太一样，我还是挺喜欢一些年轻老师、年轻教授的”

  • 他在北大孵化和投资老师与学生，开了 AI 创业与投资课。
  • 他找的是两代结合：学生懂技术和趋势，老师有过创业经验；集中在北大一个池子，靠天才吸引天才，带来其他学校的人。

10. RSI for what（Harry）#

Harry 说线性今年投得最多、拒得最多的都在 physical AI。他把它分成让机器人更聪明能干活的模型和世界模型两派，对后者有很多疑问。另一个见得多的方向是 RSI（recursive self improvement），有的想做下一个基模公司，有的做面向芯片设计、制造等领域的 RSI。

“这就好像在可能几年前，有人说我来拿 reinforcement learning……来去做一家新的公司，那只是一种方法，这不是一种创业的方式”

  • 他说这类公司初始估值通常在 1 亿美金以上，这个方向见得很多，但一个都没投。

11. 大学毕业拿 200 万做什么#

  • 戴雨森说做什么没那么重要，“不断的 pivot，不断的去换方向是创业的常态”。他自己从游戏内广告系统转到卖化妆品（聚美）。他还说现在可能都不用 200 万，用 AI 花的是 token，token 越来越便宜。
  • Harry 说他今年自己做了一个视频播客，制作和剪辑尽量用 AI，“创业这东西一定要对你好玩，才能干得下去”。
  • Patrick 说后视镜视角是做中国人一些永恒的、还没完全被解决的需求，情绪价值是其一；前视镜视角是做以前要 50 年、100 年才能做到的难题，愿意花十年去搞一把。

存疑#

  • “90% 甚至 99% 的应用层公司”那句后半没听清，“出局”是按上下文补的。
  • 短剧占中文 AI 世界 token 消耗 55% 的说法，出处只有“有个上市公司说”，公司名和口径都没给。
  • 戴雨森说的“推理效率每年可能提高 10 倍”没给比较基准和出处。
  • Harry 说的实时视频生成“20 倍以上”没给基线，是目标还是已实现没说清，也分不清是线性的被投公司还是在看的项目。
  • Harry 讲 physical AI 两派的那段录音很乱，只取了大意。
  • 第一个问题的回答（论断 1、2 及论断 5 的抽成说法）只有外部录音，未与本人录音对照。
