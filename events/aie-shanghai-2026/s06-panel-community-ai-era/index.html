据作者现场录音整理，按讲者脉络转述，不是逐字稿。其中嘉宾自我介绍和第一个问题的回答部分据现场外部录音补全，未与本人录音对照；开场和 AJ 自我介绍的前半段，两份录音都没录到。嘉宾是 AJ（WaytoAGI 创始人）、Koji（十字路口 Crossing 创始人、真格基金 Venture Partner）、曲凯（42章经创始人兼 CEO），主持人是高宁（Linkloud 联合创始人兼 CMO）。中文圆桌，无观众问答，最后一轮是每人一句话建议。说话人按上下文判断。

一句话#

三位做社区和内容的嘉宾都在说，AI 时代信息差和产品差异变小以后，线下见面带来的信任和人与人的连接反而更值钱；创业者对外发声要像做产品一样准备，攒够了再说。

论断#

1. 今年市场：焦虑，应用层被模型挤压#

Koji 用坦克打比方：基础模型像迎面开来的坦克，站在马路中间的应用创业者今年最难，大家开始要么往天上去、要么往地下钻。

“在今年站在马路中间的AI的应用创业者，其实日子是过得最艰难的”

  • 往地下钻：他列了 FDE、交易数据、infra、芯片、推理加速、中转站，没展开。
  • 往天上去：AI for science，今年很多教授和 PhD 创业，做 science、生物、AI EDA。
  • vertical agent 会不会被模型吞掉，他说"答案在风中飘"，自己也看不清。

曲凯说现在大家都很焦虑，按融资多少各有各的焦虑；大家聊得最多的是最新模型解锁了什么能力，很少再聊用户需求。他说自己更怀念 23、24 年，那时大家更纯粹。

“十年前做 VC 的时候，大家聊第一反应难道不是应该聊用户的需求是什么”

  • 后期公司怕上不了市；中期怕热点过去、模型和产品没出来、要不要转型；拿钱少的做不出结果。

2. 社区成员从"玩"转向真创业（AJ）#

AJ 说今年社区里的人从去年的玩家变成真正开始创业。原因之一是 personal agent 能让 AI 帮人完成最后一步，他自己最常用的 personal agent 能完成订单和交易，没说是哪个产品。

“中间就是这些OPC的伙伴们，他们是能够从公司里边跳槽出来，还能够赚到和公司原来一样的钱，但是生活更自由”

  • WaytoAGI 把成员分成金字塔三层：底层是入门、在工作生活里用好 AI；中间是 OPC（一人公司）；顶层是拿融资、做更大商业化的创业者。
  • 园区招 OPC 的标准是营收至少能养活自己，他承认"有可能是我们把它掐尖了"。
  • 他说投资变得越来越谨慎，“因为人人都可干了”。

3. 社区从一份文档长成实体空间，信任替代雇佣（AJ）#

WaytoAGI 按文档、群、直播、多城线下聚会、实体空间一步步加深接触频率。商务能力强的人接了订单，分给社区里在线下见过面、知根知底的伙伴，可以不用雇佣制。

“我接了一个订单，或者是一个需求，他是商务能力比较强，我可以让我去接了订单以后分布给其他社区里面信任的伙伴”

  • 微信群、飞书群上千个，线下覆盖 52 个城市。
  • 亦庄一栋 8 层小楼，招了上百个 OPC；成都园区 8000 平方米已开业。
  • 和红杉资本合办孵化营，下一期在筹备。

4. 社区可以当产品首发渠道（AJ）#

他说成员做产品发布时，第一时间会想到来社区发布。

  • 一个做短漫剧工具的成员在社区做了一场直播，当天新增 200 个用户，一个月卖出"十几万"，单位没说。

5. 内容给灵感，社群给陪伴（Koji）#

Koji 说自己当年坚定做互联网创业，是因为在五道口的创业社区里被肯定过。他认为新一代创业者要的东西没变，很多人来活动不是为听某个分享，是来见朋友、看同类在干什么。

“灵感和机会是内容，陪伴和连接是社群”

  • 十字路口坚持周更，从音频做到视频，最近开始录和嘉宾边开车边录的公路播客。
  • 上海 AI Hacker House 在公园里一栋 300 多平的小楼，办 AI 开放麦（每人上台 10 分钟）和周日黑客松。

6. 线下的化学反应线上替代不了（Koji）#

他说十字路口最重要的是内容，仍做很多线下活动，是因为线下见面的 chemistry 线上取代不了。常规大会上多半只能和熟人聊，于是和 Table for six 合办活动，报名后随机六人一桌。

“你报名之后，他会把 6 个人分成一个小组，告诉你们今天晚上，比如说在上海静安区某一个酒吧的某一个桌子，那就是你们的据点”

  • 第一次 300 多人报名，50 多桌，全国 5 个城市，每桌 6 个互不认识的 AI 从业者。还会办第二场，时间未定。

7. 商业模式决定一切，42章经选了交易（曲凯）#

曲凯说 42章经做了约十年，结论是做的所有东西最终由商业模式决定。媒体和社群只有两条变现路：广告跟流量挂钩，交易跟社群挂钩，他们放弃广告，往交易走。

“我们就是在越来越往高客单、精品和高质量高门槛这条路上去走吧”

  • 公众号加播客全网约 50 多万粉丝，更多在做背后的社群活动、FA 和投资。
  • 试过几千人的社群、高客单商学院、饭局。没给收入数字。

8. 嘉宾上播客，最多是为了招人（曲凯）#

他说很多人以为嘉宾来上播客是为了 PR，交流下来占比最高的诉求是招人。活动对他们是工具箱，每种活动先想清楚要什么、局限在哪。

“所有嘉宾来最多的占比是他想招人，招聘反而是大家最核心的诉求”

  • 创业者参加活动的其他诉求：新的输入、认识新的人、情感上的慰藉。他拿新东方英语培训打比方，回去想想没讲什么，但打了鸡血。
  • 没给占比数字。

9. 对外发声要保持势能（曲凯）#

他说一个人再有干货，也经不起每周出来聊；要想好什么时候释放，针对不同人群和渠道分开释放。

“很多人是他积累了 10 年的职业经历，他能聊一期特别精彩的播客，然后他可能要下一期的话，他得再积累个三五年起码”

  • 分人群的例子：一次面向想招的 researcher，一次面向 C 端用户，一次给投资人看。
  • 结尾一句话建议：媒体要做到热点加干货，光追热点留存不下来，光有深度起不来。

10. 做 PR 套用做产品的方法（Koji）#

Koji 接着曲凯的话补充：

  • 灰度发布：先找几个朋友，把准备讲的叙事讲给他们听，拿反馈。
  • 用户调研：找到目标受众听反馈，这次 PR 是 to VC 还是 to 用户要先定。
  • 找做过的人：重要 PR 前找操盘过类似 PR 的创始人或 PR 专家。

“1000 次 PR 可能是 1000 个不同的 case，要非常 case by case 的看”

11. 信息差变小，表达能力更重要（AJ）#

AJ 说从去年到今年信息差缩短得特别大，产品差异化太难，大厂又有免费 token 和各种 work agent 能做通用的事。他觉得中国创业者的 presentation 能力偏弱，go to market 同等重要。

“从去年到今年，我感觉信息差缩短了特别的特别大，就没有太多的信息差了”

  • 对比对象是他参加过的 OpenAI 某活动路演、日本的路演、YC 的路演，那边演讲能力强，也更多用视频表达。
  • 他转述前两天看到的一篇写 Manus 产品团队的文章：先不写 PRD，写 PRV（V 是 video），功能开发前先做成发布视频，让同事以用户视角看行不行。
  • 他把 42章经和十字路口的播客当工作台挖信息，理由是有些内容是聊出来的，不是准备出来的。

12. 最后一轮建议#

  • Koji：“悲观者往往正确，乐观者才能成功”，好运气发生在一直 build 的过程中。
  • AJ：可能很容易被大厂覆盖，但可以继续做，不要放弃。
  • 高宁：迷茫时多加入不同社区，看同路人在做什么。高宁在圆桌前段还提到，湾区和日本越来越多创业者和第三方社区紧密合作，线下有时比线上效果好，因为能真实面对用户。

存疑#

  • AJ 说短漫剧工具一个月卖出"十几万"，单位和口径没说。
  • AJ 提到的 OpenAI 路演活动名没听清，同处说到的"T 轮融资 / Token 轮融资"含义不明。
  • PRV 出自 AJ 转述的一篇文章，作者身份未核，不是 Manus 的人在现场说。
  • Koji 第一次 Table for six 活动的城市数，一处听成 6 个、一处 5 个。
  • 亦庄上百个 OPC、成都 8000 平、红杉孵化营都只出现在开场自我介绍里，一处来源，未核。
