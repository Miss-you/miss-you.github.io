From Idea to Viral Launch: How I Built a 3D Little Prince Game with AI

据现场外部录音整理，未与本人录音对照。讲者自述是 AI 独立开发者，也是一名 AI influencer，自称完全不懂建模、不太懂游戏；中文演讲，无问答环节。前半讲为什么能做成，后半讲制作流程和经验；幻灯片未见，只能从口述还原。

一句话#

一个不懂建模的人 16 天做出能在 Unity 里渲染的 3D 游戏，他认为靠的不是技术，而是先摸清新模型的能力边界、有审美、懂社媒传播。具体做法是用参考图（尤其俯视图）定目标，让 agent 在 Blender 和 Unity 里搭场景，再用"多机位截图对参考图盲审"这类 loop 让 agent 自己迭代到 1:1。

论断#

1. 先知道 AI 的能力边界#

“第一个，我觉得最重要的是你现在必须要知道AI的边界是什么。”

他有两个办法。一是常看 X 上拿到内测资格的人分享的 use case；二是新模型一发布，就用自己固定的一套提示词测 3D、前端和代码。

  • 他举的例子：Opus 5.5 用中等的 effort 就能做出好的 3D case，他由此判断 AI 的 3D 能力有了突破。
  • GPT-6 Astra 出来时，他用一个提示词直接复刻出一个 3D 场景，判断 AI 已经到了能做 3D 建模的临界点，之后才做《小王子》。他说以前 AI 生成的 3D 建模全是 slop，做得很差。
  • 游戏在家里 16 天做完，没说传统做法要多久。

“因为其实在做《小王子》的时候我是非常自信的。我是知道它一定能做出这样的游戏。所以当时只是需要花费时间。”

2. 审美可以练#

他说大学同学吐槽过他审美不行，后来做自媒体发现有审美的作品浏览量就高。他的做法是把觉得审美好的 case 都记进 Notion 数据库，由 agent 帮忙整理，自己定期回看，既练眼光，也当灵感库。

“确实我也觉得我当时的审美能力不太行，但是我觉得所有的能力都是你可以培养的。”

3. 懂社媒：X 是国内 AI 内容的上游#

他认为 building in public 的关键是懂社交媒体。他的判断是 AI 的一手消息诞生在 X，国内媒体会拿 X 上的爆款当选题，所以 X 上起量后，国内转发是可以预期的。

“因为很多的AI的一手新闻都是在X诞生，所有国内的相关的媒体它都会关注X上的一些爆款内容去作为他们的选题。”

  • 发布前一天，他在饭局上对朋友说能在 X 上跑 300 万流量。
  • 他报的结果：X 帖子 3370 万曝光，全网曝光超过 4000 万，小红书、抖音话题浏览千万以上，微信公众号被机器之心、量子位等转发。发布第二天国内媒体和 KOL 开始转发。这些数字都是讲者自报，没给统计口径。

4. 制作流程：参考图先行，俯视图最关键#

  • 分工：一个模型负责整体设计，Opus 5.5 写代码，Codex 做迭代。3D 生成用 Tripo，同时要装 Blender 和 Unity 的 CI。
  • 场景三步：先生成参考图，包括俯视图和一张含场景细节的完整参考图；再把技术路线告诉 AI，让它分析参考图，判断哪些资产用 3D 生成、哪些直接在 Blender 里做；最后在 Unity 里对照参考图复刻。

“因为俯视图AI可以详细的参考你的俯视图去了解整个场景的一个布置”

  • 角色：生成 3D 人物模型；因为用 Mac，技术路线选了 AutoRig Pro，这条路线是和 AI 聊出来的。让 AI 在 Blender 里调这个插件完成绑骨和蒙皮，先做简单测试，排查拉扯和穿模。
  • 动作：用一个动作库，让 AI 按 PRD 和剧情分析需要哪些动作，他自己下载上传。特定动作（疑为小王子浇花，转写不清）基于动作库微调，把细节描述给 AI。

5. 用 loop 让 agent 自检，人及时纠偏#

“就第一个我觉得最重要的是你一定要去利用好loop”

他在幻灯片上给了三个 loop 提示词：

  • 让 agent 多机位截图，和参考图盲审比对，直到场景图和参考图 1:1。
  • 真实感不足的元素，让 agent 搜真实照片建一个数据库，对照着打磨。
  • 让 agent 代入小王子的视角自己玩游戏，找场景里的问题。他说有的 bug 他也不知道是什么，agent 自己就修了。

他同时强调 Human in the loop 非常重要。例子是云：一开始像棉花糖一样，非常丑，后来改用真实图片库的方法，做出了真实的云海。

最后一条是做的时候及时把踩坑沉淀成 md 文件。做完小王子角色后，他把和 AI 交互中遇到的问题写成 md，后续角色的绑骨蒙皮就快了很多，没给前后耗时。

6. AI 带来技术平权，最重要的是想法#

“我所有的都是去问AI，它给我的方案是什么，我一个一个去测试，找到最佳的方案。但是我觉得最重要的是想法”

他解释了为什么用一半时间讲为什么能做成，而不是实操。

存疑#

  • 负责整体设计的模型名没听清，前后两处说法也不一致。
  • 用 GPT-6 Astra 测试时复刻的是什么 3D 场景，没听清。
  • “Blender CI 和 Unity CI"的 CI 所指不明，疑为 CLI。
  • 沉淀经验的 md 文件名没听清。
  • 动作库名称、三个 loop 提示词和参考图提示词的全文都在幻灯片上，口述里没有。
