## 一句话

市面上的 Personal Agent 在工程上大同小异，都在替人解决"烦恼"和满足"欲望"，这是向外的；YouMind 要做的是向内的：营造一个让人和 AI 一起创作、以创作促学习和成长的环境。他的理由是人是环境的反应器。

## 论断

### 1. 各家 Personal Agent 能力趋同，区别在场景

他把各家产品拆成四块：Memory（理解你、建 profile）；连接器（Gmail 等，让 agent 看见你看见的世界）；主动性，比 coding agent 更主动，有定时任务和主动触达；权限和隐私，他说目前可能真正做好的不多。

> "所以从工程技术上来看的话，其实整个那Personal Agent可以说能力上是差不多的……核心区别是那场景"

- 他自己用了近两个月 Claude Tag，说它"是体感最好的"，因为它"知道是什么时候跟你聊天，什么时候不跟你聊天"。
- 现场举手，投屏上这些 Personal Agent 用过的约五分之一，他说"比我想象中要少"。是目测。
- 场景举例：有产品连上 Gmail 后"做了一个比Gmail还好的邮件客户端"；处理杂事、看邮件、会议纪要、写周报、关注身体健康。

### 2. 现有场景只有两类：解决烦恼、满足欲望

烦恼类如取消订阅、订票、处理邮件；欲望类如自媒体圈流行的"内容自动化工厂"，用碎片时间涨粉、挣钱。他认为两类都是向外的。有人的愿景是 AI 做掉烦人的事、人把时间花在想做的事上；他不认同，说多数人日常杂事没那么多，时间多半被短剧、短视频拿走。

> "真的能让我们把各种那烦恼的事情和那欲望都满足掉之后，我们真的会去干我们想做的事情吗？这答案肯定是那否定的。"

- 深夜刷手机，他说心理学上是一种补偿机制：白天身不由己，睡前刷手机是"人在夺回自己那个选择权"，Personal Agent 帮不了这个。
- 他把这部分落在一句话上："最重要的不是Agent，是前面那个Person"。

### 3. 从消费侧走向创作侧

内容消费从门户、搜索走到今日头条、抖音、红果的推荐流，人一直被推荐牵着走。他认为被动消费已经到头，下一步是创作；参会的人内心都有想做的事，需要一些环境把它点燃，AIGC 给了每个人创作上的选择权。

> "其实消费侧，我们那被动消费，我们丧失选择权的消费，其实已经已经到了尽头。"

- 他说无论微信、YouMind 还是任何产品，都在营造一个环境，因为人是环境的反应器。收尾时他又说了一次这句。

### 4. 很多人用 YouMind 做 PPT 是给自己看的

他起初以为 YouMind 在进军 PPT 赛道，要和 Gamma 等资金更雄厚的对手竞争；做了用户访谈后改了判断。

> "很多人在YouMind的做PPT是做给自己看的，中间做15个PPT里面，一个月平均两天做一个PPT，中间15个里面，只有一两个会给别人看。"

- Max 档（月付 100 美元）付费用户"上千名"，人均每月约 15 个 PPT，其中一两个给别人看。这是 YouMind 自家数据加用户访谈，没给统计口径和样本量。
- 由此他提出 ToB、ToC 之外还有 ToM，即"给自己看"的需求。旁证是 Google NotebookLM 上很多人做播客、视频概览、信息图也是给自己看，没给数据。

### 5. 两个场景：Create to Learn 和创作的正反馈

第一个场景是费曼学习法：把东西用自己的方式讲出来、做成 PPT 或写成文章。有朋友开玩笑说 YouMind 是"全球第一个"费曼 Agent。第二个场景是创作带来的乐趣：接商单、做自媒体变现，第一次做图文发小红书拿到第 1、10、100 个赞，得到连接感。他说学习和创作要能正循环。

> "其实不存在怀才不遇，但是存在自己没有才华……这些天赋点要变成才华，是需要经过刻意练习的。"

- 他说刻意练习"可能不一定要到10万小时，但是几万小时是需要的"，AI 能让没拍过影视、没做过音乐的人加快这个过程。
- 他说 YouMind 的功能"跟大家都差不多，就是那Memory啊，Skill啊"。

### 6. 演示：这场的幻灯片就是在 YouMind 里做的

他在 YouMind 新建一个任务，说要来 AIE 做分享，初稿出来后多轮对话修改，同时也是在梳理自己的思路。偏好只要说一次，比如后续页面不要带页脚，它就能记住；agent 也记得他过去一年多和 YouMind 的交互和资料。

> "他懂的是YouMind的过去和当下，但是我知道的是YouMind的未来，所以我跟他就会形成一种很好的那互补关系"

他说用户在 YouMind 里通常经历四个阶段：
- 像用豆包一样直接说，这时输出差异主要来自模型，跟产品关系不大。
- 带上私有资料（文件、日记、录音），能帮你写周报，但还谈不上创作。
- 把某类 PPT 的做法沉淀为一个 Skill，减少重复。
- PPT 一键转视频，一稿多用。

### 7. 通用 Personal Agent 交给大厂，创业者做创作型 Studio

最后一页他讲 YouMind 的定位：很多产品顺着贪嗔痴做，让人放弃选择权；Personal Agent 有机会让人更有"戒定慧"。他把"戒"解释为取舍，知道不做什么；"定"是培养专注。

> "确实我觉得Personal Agent可能交给那大层面去玩吧，那是对于创业者来说，也许做一个跟环境相关的……做一个更好的创作型的Studio，可能会更有机会。"

## 存疑

- 录音从讲话中途开始，缺开头的自我介绍和开场。
- 他讲产品时间线时提到多款 Personal Agent，多数产品名没听清；Claude Tag 的发布日期（他说 6 月 23 日）是口述，未核。
- 他引了一位 Muse 方面人士的愿景，说话人是谁没听清。
- "10 万小时 / 几万小时"与常见的"1 万小时"说法不符，可能是口误。
- "贪嗔痴""戒定慧"是按上下文推断的词，原话听不清。
- 他说 PPT 用"图片法"生成所以页脚难改，疑指整页以图片生成，未确认。
- "每月人均 15 个 PPT"的原话里先说了"每周每个月"，按后文"一个月平均两天做一个"理解为每月。
