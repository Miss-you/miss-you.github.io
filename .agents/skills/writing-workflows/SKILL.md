# Writing Workflows

先读项目 `AGENTS.md`。面向作者自己的笔记和面向公开读者的文章分别处理；同时交付两者时由项目 `thinking-to-knowledge` 编排。

执行 [项目写作流程](references/project-workflow.md)。Hydrogen ACP 调用见项目 `thinking-to-knowledge/references/runtime.md`，工具与 lint 位置见项目的 `写作/writing-workflows.md` 或 `kb/writing-workflows.md`；存在 `写作/writing-workflows.local.md` 时再读本机覆盖。这些配置优先于上游流程中的工具默认值。

每次新增或实质修订知识库正文，写作前主动按 [图表选择与验收](references/visual-structure.md) 判断哪些内容适合表格、Mermaid 或原有段落/列表；把选择及阅读收益交给项目配置的 agy 写作会话，最终审稿再核对证据边界与手机渲染。无需等用户另行要求图表，不设每篇必备图表的要求。

方法依据与固定文本版本见 [依赖来源](references/provenance.md)。本入口不依赖用户目录中的写作技能或另一个仓库的存在。
